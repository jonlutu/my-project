# 📚 Jonathan's Learning Project

A beginner-friendly repository to learn **Git**, **Python**, and **GitHub collaboration**.

## 🎯 Project Goals

- ✅ Learn basic Git operations (commit, branch, merge)
- ✅ Practice Python programming
- ✅ Set up collaborative workflows with OpenClaw AI
- ✅ Understand GitHub features (Pull Requests, Issues, etc.)
- 🔄 Build more advanced projects over time

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed
- Git configured locally
- GitHub account set up

### Running the Project

```bash
# Clone the repository
git clone https://github.com/jonlutu/my-project.git
cd my-project

# Run the Python script
python3 hello_world.py
```

## 📁 Project Structure

## 🔧 Development Workflow

This project uses **feature branches** for development:

1. **Create branch**: `git checkout -b feature-name`
2. **Make changes**: Edit files, add features
3. **Commit**: `git commit -m "Description"`
4. **Push**: `git push -u origin feature-name` 
5. **Pull Request**: Review and merge on GitHub
